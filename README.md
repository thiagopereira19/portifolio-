## Como rodar

Abra o `index.html` no navegador, ou use a extensão Live Server do VS Code.

## Estrutura

- `index.html`: estrutura da página
- `style.css`: estilos e tema claro/escuro
- `script.js`: dados dos projetos (array `PROJETOS`), tema, animações e formulário de contato
- `images/`: fotos e prints dos projetos
- `curriculo.pdf`: currículo para download
